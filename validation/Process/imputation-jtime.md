## JTime
Tous les collaborateurs de CIS doivent imputer des heures de travail sur des projet ou sur une structure de management.
JTime est l'outil permettant de faire cela. Avant de pouvoir imputer, il est impératif d'obtenir un "code d'imputation" pour indiquer sur quels sujets vous avez travaillé.
Ce code s'obtient auprès du Program Manager (PM) de votre projet.

## Une fois le code d'imputation obtenu, voici comment imuter vos heures :
1. Ouvre le lien de l'outil JTime : https://jtime.online.corp.thales/gai/ ;
2. Clique sur "Standard" ;
3. Sélectionne la semaine que tu souhaites renseigner ;
4. Déclarer tes heures ou journées travaillées (selon la nature de ton contrat) ;
5. Attribut un code d'imputation pour chaque projet sur lequel tu as travaillé sur la semaine sélectionnée ;
6. Coche la case "Semaine Validée", puis clique sur le bouton "Enregistrer" ;
7. Répète ces étapes pour chacune des semaines à remplir.
